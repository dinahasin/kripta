### Session Setup

Session de brainstorming structurée pour explorer tous les aspects techniques, architecturaux et UX de Kripty, un gestionnaire de mots de passe et crypteur de dossiers utilisant des méthodes de cryptage similaires à WannaCry (mais bienveillantes), avec certificats, hash et chiffrement pour sécuriser les données utilisateur.

### Contraintes Techniques

**Stack technique (non négociable):**
- **Langage:** Python
- **Framework UI:** PySide6 (non négociable)
- **Gestion des UI:** Fichiers .ui doivent être transformés en classes .py pour faciliter la compilation
- **Approche:** Architecture professionnelle avec méthodes de builds modernes

**Gestion des certificats et clés de sécurité:**
- **Méthode de configuration:** Certificat configurable via clé USB ou média amovible (CD, téléphone, etc.)
- **Intégration dans l'app:** Le certificat doit être compilé dans l'application pour que seule l'app le connaisse
- **Modèle de récupération:** Similaire à la récupération GitHub mais réutilisable (pas à usage unique)
- **Stockage:** Certificat stockable n'importe où (médias amovibles, cloud, etc.)
- **Dernier recours (optionnel):** Support pour clés hardware comme celles des portefeuilles de cryptomonnaie (non obligatoire)
- **Objectif:** Système de certificat robuste avec multiples options de stockage et récupération
